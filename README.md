# Сайт Александра Горчакова

Персональный сайт эксперта: ИТ-директор и архитектор цифровой трансформации (госсектор и финансы). Сейчас опубликован по адресу https://a-nas.ru/sasha2/.

Сайт статический: страницы генерирует сборщик на Node.js без внешних пакетов. На сервере нужен только PHP для формы обратной связи.

## Как посмотреть

- **Опубликованный сайт:** https://a-nas.ru/sasha2/
- **Черновик на GitHub Pages:** https://gdm2009.github.io/gorchakov-site/ — пересобирается сам после каждой правки в `main` (`.github/workflows/pages.yml`), закрыт от поисковиков, форма там не работает.
- **На своём компьютере (Windows):** установить Node.js с https://nodejs.org, скачать репозиторий (Code → Download ZIP), распаковать и дважды щёлкнуть `smotret.bat`. Откроется http://localhost:8080. Остановить: закрыть чёрное окно.

## Быстрый старт

Нужен **Node.js 18+**. Устанавливать ничего не надо.

```
npm run dev          # собрать локальную версию в dev/ и открыть http://localhost:8080
npm run build:local  # только собрать dev/
npm run serve        # только запустить сервер для уже собранной dev/
```

Боевая сборка под конкретный адрес (результат в `novyi-sait/`):

```
node tools/build.js https://example.ru            # сайт в корне домена
node tools/build.js https://example.ru /expert    # сайт в подпапке
```

То же самое делают `./sobrat.sh` (macOS/Linux) и `sobrat.bat` (Windows). Как загрузить на хостинг и что проверить: `ПРОЧТИ.md`, разделы 1, 3–6.

Локальный сервер не выполняет PHP, поэтому форма обратной связи на `localhost` не отправляется. Её проверяют на хостинге.

## Структура проекта

```
README.md                 этот файл
ПРОЧТИ.md                 исходная инструкция автора по переносу на хостинг
package.json              команды npm run dev / build / serve
tools/build.js            сборка одной командой (оба сборщика по очереди)
tools/serve.js            локальный сервер для просмотра dev/
sobrat.sh, sobrat.bat     боевая сборка под адрес (вызывают tools/build.js)
smotret.bat               посмотреть сайт локально в Windows двойным щелчком
.github/workflows/pages.yml  черновик на GitHub Pages
ishodniki/
  _src/sasha/             СОДЕРЖАНИЕ и 3D-кабинет
    index.html            исходник 3D-кабинета + блок CONTENT (тексты об эксперте, цифры, кейсы, услуги, карьера)
    build.js              SERVICE_PAGES (подробные тексты услуг), POST_SERVICE, TOPICS; собирает кабинет
    blog/*.md             статьи блога (одна статья = один файл)
    README.md             правила оформления статей
  _src/sasha2/            ОФОРМЛЕНИЕ и раскладка по страницам
    build.js              главный сборщик сайта; в начале настройки CONTACTS, VERIFY, METRIKA, LIVE
    site.css              стили
    static/               фото эксперта, шрифты, значки, og.jpg
    g/                    баннер первого экрана и фон тёмных полос
    send.php.txt          шаблон обработчика формы
    htaccess.txt          настройки Apache
    tools.py, images.json, indexnow-key.txt   загрузка графики из Higgsfield и IndexNow (для автоматики)
    README.md             подробное устройство сборщика
  a-nas.ru/sasha/         готовые части, которые сборщик копирует в сайт
    index.html            собранный 3D-кабинет (пересобирается шагом 1)
    img/                  фото и картинки статей
    neurogame/            готовая сборка игры
  .github/workflows/      автоматика со старого репозитория (для справки, не запускается)
dev/, novyi-sait/         результаты сборки (в git не попадают)
```

Как идёт сборка (`tools/build.js`):

1. `ishodniki/_src/sasha/build.js` вставляет статьи и список файлов игры в исходник кабинета и пишет `a-nas.ru/sasha/index.html`. Побочно он создаёт там же страницы старой версии сайта; они не нужны и исключены из git.
2. `ishodniki/_src/sasha2/build.js` берёт тексты из `_src/sasha/`, оформление из `_src/sasha2/`, копирует кабинет, игру и картинки и выкладывает весь сайт в `dev/` или `novyi-sait/`.

Проверено 16.11.2026: сборка с адресом `https://a-nas.ru/sasha2` даёт файлы, побайтно совпадающие с опубликованной копией из архива.

## Где что править

| Что поменять | Где |
|---|---|
| Телефон, почту, Telegram | `CONTACTS` в начале `ishodniki/_src/sasha2/build.js` |
| Тексты об эксперте, цифры, компетенции, кейсы, карьеру, короткие описания услуг | блок `CONTENT` в `ishodniki/_src/sasha/index.html` |
| Подробные тексты услуг | `SERVICE_PAGES` в `ishodniki/_src/sasha/build.js` (порядок как в `CONTENT.services`) |
| Новая статья | файл `ishodniki/_src/sasha/blog/ГГГГ-ММ-ДД-slug.md` (шапка описана в `ishodniki/_src/sasha/README.md`), строка в `POST_SERVICE` |
| Картинка статьи | `ishodniki/a-nas.ru/sasha/img/blog/<slug>-1200.webp`, `-720.webp`, `-440.webp`, `-1200.jpg` (16:9) |
| Оформление | `ishodniki/_src/sasha2/site.css` |
| Фото, значки, картинка для соцсетей | `ishodniki/_src/sasha2/static/` |
| Яндекс Вебмастер, Google Search Console, Метрика | `VERIFY` и `METRIKA` в `ishodniki/_src/sasha2/build.js` |

После любой правки: `npm run dev`, посмотреть результат, затем боевая сборка и загрузка на хостинг.

## Изменения относительно исходного архива

- Игра перенесена из `sait/neurogame/` в `ishodniki/a-nas.ru/sasha/neurogame/`, где её по умолчанию ищут оба сборщика. Папка `sait/` (опубликованная копия) удалена: она целиком воспроизводится сборкой. Исходный архив `gorchakov-site.zip` сохранён в файлах проекта.
- Добавлены `README.md`, `package.json`, `tools/build.js`, `tools/serve.js`, `.gitignore`. `sobrat.sh` и `sobrat.bat` теперь вызывают `tools/build.js` и пересобирают в том числе кабинет. Код сборщиков не менялся.

## Известные ограничения

- Исходников игры «Нейрогонка» здесь нет (они в репозитории GitHub `robot-sites/sites`, `_src/sasha/neurogame-src/`). Менять можно только сайт и кабинет.
- Доставка писем из формы не проверена; нет страницы политики обработки персональных данных; тексты услуг не выверены экспертом (из `ПРОЧТИ.md`).
- 3D-кабинет и игра берут шрифты с Google Fonts.
