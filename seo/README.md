# Файлы для корня домена a-nas.ru

Сайт лежит в подпапке `/sasha2/`, а поисковики и ИИ-боты ищут `robots.txt` и `llms.txt` только в корне домена. Поэтому два файла отсюда нужно положить в корень a-nas.ru (рядом с папкой `sasha2`):

| Файл здесь | Куда положить | Зачем |
|---|---|---|
| `robots-dlya-kornya.txt` | `a-nas.ru/robots.txt` (заменить текущий) | открывает сайт поисковикам и ИИ-ботам и сообщает адрес карты сайта |
| `llms-dlya-kornya.txt` | `a-nas.ru/llms.txt` | подсказывает ИИ-ассистентам, где описание эксперта |

`robots-dlya-kornya.txt` пересоздаётся при каждой сборке (`node tools/build.js`). Если сайт переедет на свой домен, эти файлы не нужны: сборка сама положит `robots.txt` и `llms.txt` в корень.
