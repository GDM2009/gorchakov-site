# a-nas.ru/sasha2 — классическая версия сайта Александра Горчакова

Вторая графическая версия сайта: обычные страницы без 3D. Содержание общее с действующим сайтом `a-nas.ru/sasha`.

- `build.js` — сборщик (Node, без зависимостей). Запуск из корня репозитория: `node _src/sasha2/build.js`. Результат: `a-nas.ru/sasha2/`.
- `site.css` — оформление. Сборщик сжимает его и кладёт в `assets/site.<метка>.css`.
- `tools.py`, `indexnow-key.txt` — загрузка графики и уведомление Яндекса и Bing о новых страницах (IndexNow).
- `static/` — фото эксперта (исходное, не стилизованное), значки, картинка для соцсетей `og.jpg`.
- `htaccess.txt` — настройки сервера для папки (копируется в `a-nas.ru/sasha2/.htaccess`).

## Откуда берётся содержание

Здесь текстов нет. Сборщик читает их из исходников действующего сайта и ничего в них не меняет:

- `_src/sasha/index.html`, блок `CONTENT`: имя, роль, абзацы «о себе», цифры, компетенции, кейсы, услуги, карьера.
- `_src/sasha/build.js`: `SERVICE_PAGES` (подробные тексты услуг), `POST_SERVICE`, `TOPICS`, `ROLE`.
- `_src/sasha/blog/*.md`: статьи. Картинки статей: `a-nas.ru/sasha/img/blog/` (их сжимает автоматика действующего сайта).

Новая статья: добавить файл в `_src/sasha/blog/` по правилам из `_src/sasha/README.md`, затем запустить оба сборщика. У каждой статьи свой адрес `/sasha2/blog/<slug>/`.

## Сайт самостоятельный

Всё, что видит посетитель, лежит внутри `a-nas.ru/sasha2/`, ссылок на `/sasha/` нет. При каждой сборке сборщик копирует из опубликованных файлов действующего сайта:

- `a-nas.ru/sasha/index.html` → `sasha2/kabinet/index.html` (3D-кабинет; адреса внутри заменяются на адреса этой версии);
- `a-nas.ru/sasha/neurogame/` → `sasha2/neurogame/` («Нейрогонка», около 55 МБ; её ссылки относительные, правок не требуют);
- `a-nas.ru/sasha/img/` → `sasha2/img/` (картинки статей).

Исходники кабинета и игры по-прежнему ведутся в `_src/sasha/` (их правит чат основного сайта); сюда попадают их готовые сборки. Автоматика пересобирает sasha2, когда меняются кабинет, игра или картинки.

## Настройки в начале build.js

- `LIVE` — `true`: сайт открыт для поиска, `canonical` на себя (решение владельца от 15.11.2026). `false`: страницы закрыты и указывают на `/sasha/`.
- `CONTACTS` — почта, телефон, Telegram. На эту почту приходят письма из формы. Если имя в Telegram не указано, кнопка открывает чат по номеру телефона.
- `VERIFY`, `METRIKA` — коды Яндекс Вебмастера, Google Search Console и номер счётчика Метрики.
- `TOPIC_MIN` — со скольких статей у темы появляется своя страница `/sasha2/blog/tema/<тема>/`.

## Форма обратной связи

- `send.php.txt` — обработчик формы. Сборщик подставляет почту из `CONTACTS` и кладёт его в `a-nas.ru/sasha2/send.php`.
- Письмо уходит с адреса `no-reply@a-nas.ru`; копия каждого обращения пишется на сервере в `sasha2/_data/obrascheniya.csv` (папка закрыта от просмотра). Есть поле-ловушка от роботов и ограничение: 5 обращений с одного адреса за 10 минут.
- Форма стоит на главной, в профиле, на страницах услуг (тема письма = название услуги), кейсов и контактов.

## Графика

- `images.json` — исходники картинок из Higgsfield (фон первого экрана `hero`, фон тёмных полос `band`). `tools.py images` (его запускает автоматика GitHub) скачивает их и кладёт сжатые копии в `_src/sasha2/g/`, а сборщик копирует их в `assets/g/`. Чтобы заменить картинку: поменять адрес в `images.json` и удалить старые файлы `_src/sasha2/g/<name>-*.webp`.

## Переезд на другой адрес

Адрес задаётся при запуске сборщика, код менять не нужно:

```
SITE_URL=https://example.ru SITE_PATH= OUT_DIR=/путь/к/папке node _src/sasha2/build.js
```

`SITE_URL` — домен, `SITE_PATH` — папка на домене (пусто для корня), `OUT_DIR` — куда положить готовый сайт. Сборщик сам подставит адрес в ссылки, `canonical`, карту сайта, RSS, `llms.txt`, кабинет, `.htaccess` и обработчик формы; для корня домена создаст `robots.txt`. Со старого адреса нужно поставить переадресацию 301.

## Что делает сборщик для поиска и ИИ

- У каждой страницы свои заголовок, описание, `canonical`, разметка Open Graph и schema.org (Person, ProfilePage, Service, BlogPosting, Blog, BreadcrumbList, ItemList).
- `sitemap.xml` с датами и картинками, `blog/rss.xml` с полным текстом статей, `llms.txt` и `llms-full.txt` (весь сайт одним текстом для ИИ-поиска).
- В статьях: содержание, время чтения, блок автора, ссылка на услугу по теме, соседние и похожие статьи, темы.
- Предупреждает, если заголовок длиннее 70 знаков или описание длиннее 170.

## Сервер

- Правила для `/sasha2` (https, адреса без слэша) лежат в общем `a-nas.ru/.htaccess` рядом с блоком `sasha`.
- Сервер не удаляет файлы: убранная страница остаётся доступной, пока на её месте нет заглушки.
