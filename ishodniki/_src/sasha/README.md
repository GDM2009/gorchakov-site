# a-nas.ru/sasha — кабинет и блог Александра Горчакова

- `index.html` — исходник кабинета: сцена нарисована кодом. Сборщик подставляет в него статьи и кладёт в `a-nas.ru/sasha/index.html` (главная раздела), добавляя описание, разметку и текст для браузеров без скриптов.
- `blog/*.md` — статьи блога. Одна статья = один файл.
- `og.png` — картинка для соцсетей и мессенджеров.
- `build.js` — собирает всё в `a-nas.ru/sasha/`: открытые страницы, блог, `sitemap.xml`, `rss.xml`, `llms.txt` и кабинет.

## Как добавить статью

1. Создать `blog/ГГГГ-ММ-ДД-slug.md` с шапкой:

   ```
   ---
   title: Заголовок статьи
   seo_title: Короткий заголовок для поиска, до 60 знаков (необязательно)
   description: Одно-два предложения для поиска (до 160 знаков)
   date: 2026-11-15
   slug: zagolovok-latinicei
   tags: тема 1, тема 2
   image: https://… (исходная картинка 16:9, например из Higgsfield; сжатые копии GitHub сделает сам)
   image_alt: что изображено, одной фразой
   ---
   Текст в Markdown: абзацы, ## заголовки, - списки, **выделение**, [ссылки](https://…).
   ```

2. Из корня репозитория: `node _src/sasha/build.js`.
3. Commit и push. Через три минуты статья появится на сайте, в карте сайта, RSS и в окне «Блог» внутри кабинета.

## Нейроигра

- `neurogame-first-load.json` — список файлов, которые игра качает при первом входе. По нему кабинет считает проценты на шкале загрузки и заранее подкачивает тяжёлые файлы. Размеры берутся с диска при сборке; если состав игры сильно поменялся, список стоит записать заново.
- Сжатие и кеширование файлов игры включены в `a-nas.ru/sasha/.htaccess`.

## Поисковики

- Сборщик делает открытые страницы: `expert/` (профиль эксперта, услуги, кейсы), `blog/` и статьи, `sitemap.xml`, `blog/rss.xml`, `llms.txt`. Данные профиля берутся из блока `CONTENT` в `index.html`.
- `a-nas.ru/robots.txt` указывает на карту сайта.
- `.github/workflows/sasha-blog.yml` + `tools/sasha_blog.py`: после push сжимает картинки новых статей в `a-nas.ru/sasha/img/blog/` и сообщает Яндексу и Bing об обновлениях (IndexNow, ключ в `indexnow-key.txt`). После того как автоматика добавит картинки, нужна ещё одна пересборка, чтобы страницы перешли с временных ссылок на свои файлы.
- Коды подтверждения Яндекс Вебмастера и Google Search Console вписываются в `VERIFY` в `build.js`.
- Сборщик предупреждает, если заголовок длиннее 70 знаков или описание длиннее 170.

## Страницы услуг и кейсов

- `uslugi/` и `uslugi/<адрес>/` — отдельная страница на каждую услугу; тексты «когда нужно» и «что получите» лежат в `SERVICE_PAGES` в `build.js`. Названия и короткие описания услуг берутся из `CONTENT.services` в `index.html`, порядок должен совпадать.
- `keisy/` — все кейсы на одной странице, у каждого свой якорь.
- Связь статья → услуга задаётся в `POST_SERVICE` в `build.js`: для новой статьи стоит добавить строку, иначе в ней будет общая ссылка на все услуги.
- `404.html`, значки сайта `img/favicon.*`, содержание в статьях (от трёх подзаголовков) создаются автоматически.

## Адреса (с 15.11.2026)

- `/sasha/` — главная: 3D-кабинет, без пароля, открыт для поиска (с 15.11.2026).
- `/sasha/expert/` — профиль эксперта (резюме) обычной страницей.
- `/sasha/kabinet/` и `/sasha/b/` — старые адреса кабинета, перенаправляются на `/sasha/` (правило в `.htaccess` и заглушка в папке).

## Нейрогонка (3D-остров)

- Исходники игры: `_src/sasha/neurogame-src/`, подробная инструкция в её `README.md` (раздел «Кто ведёт игру и как идёт выпуск»).
- Опубликованная сборка: `a-nas.ru/sasha/neurogame/`. Руками её не правят: только пересборкой из исходников.
- Сборка идёт на Mac владельца (клон `~/Projects/gorchakov-site/sites`), после неё обязательно `node _src/sasha/build.js`.
- Карточки услуг в игре ведут на страницы `uslugi/<адрес>/`: при смене адреса услуги в `SERVICE_PAGES` поправить и `neurogame-src/sources/data/lab.js`.
