# Сайт Александра Горчакова: архив для переноса на другой хостинг

Архив собран 15.11.2026. В нём всё, чтобы развернуть сайт на новом хостинге и дальше его вести: готовые файлы сайта, исходники и сборщик.

Сейчас сайт работает по адресу https://a-nas.ru/sasha2/.

## Что в архиве

| Папка или файл | Что это |
|---|---|
| `sait/` | Готовый сайт, точная копия того, что опубликовано на `a-nas.ru/sasha2/`. Все ссылки внутри ведут на этот адрес, поэтому на другом домене эти файлы как есть работать не будут. Отсюда же сборщик берёт игру «Нейрогонка» (`sait/neurogame/`, около 55 МБ). |
| `ishodniki/` | Исходники: сборщик, оформление, тексты, статьи блога, картинки, исходник 3D-кабинета. |
| `sobrat.sh`, `sobrat.bat` | Сборка сайта под новый адрес одной командой (macOS/Linux и Windows). |
| `ПРОЧТИ.md` | Эта инструкция. |

## Как развернуть на новом хостинге

### 1. Что нужно от хостинга

- Веб-сервер **Apache** с поддержкой файлов `.htaccess` (модули `mod_rewrite`, `mod_headers`, `mod_deflate`). Подойдёт почти любой виртуальный хостинг.
- **PHP 7.4 или новее** с работающей функцией `mail()`: на нём работает только форма обратной связи. Остальной сайт — обычные файлы.
- **HTTPS** (сертификат Let's Encrypt или любой другой).
- Около 70 МБ места.

На сервере nginx сайт тоже заработает, но правила из `.htaccess` придётся перенести в настройки nginx вручную (страница 404, сжатие, сроки хранения файлов, запрет доступа к папке `_data`).

### 2. Собрать сайт под новый адрес

На своём компьютере нужен **Node.js 18 или новее** (https://nodejs.org). Других программ и установки пакетов не требуется.

Сайт в корне домена:

```
./sobrat.sh https://example.ru
```

Сайт в подпапке домена:

```
./sobrat.sh https://example.ru /expert
```

В Windows те же команды с `sobrat.bat`.

Появится папка `novyi-sait/`. Сборщик сам подставит новый адрес во все ссылки, в карту сайта, RSS, файлы для ИИ-поиска, 3D-кабинет, `.htaccess` и обработчик формы. Для сайта в корне домена он также создаст `robots.txt`.

### 3. Загрузить на хостинг

Загрузите **содержимое** папки `novyi-sait/` в корень сайта (или в выбранную подпапку). Важно не потерять скрытые файлы `.htaccess` (в корне и в папке `_data`): некоторые программы для загрузки их не показывают.

Папка `_data` должна быть доступна PHP для записи: туда пишется копия каждого обращения из формы.

### 4. Проверить

1. Открывается главная, страницы услуг, блог, статья, контакты.
2. Открываются 3D-кабинет (`/kabinet/`) и игра (`/neurogame/`).
3. Несуществующий адрес показывает страницу «Такой страницы нет».
4. Форма обратной связи: отправьте сообщение и проверьте почту `ale.gorchakov@gmail.com`, включая папку «Спам».
5. Адрес `/_data/` в браузере закрыт (ошибка 403).

### 5. Если сайт стоит в подпапке

Сервер должен сам добавлять косую черту к адресу папки (`/expert` → `/expert/`). Обычно так и есть. На `a-nas.ru` это было отключено, поэтому в корневом `.htaccess` домена стояли правила:

```
RewriteCond %{HTTP:X-Forwarded-Proto} !=https
RewriteRule ^sasha2(/.*)?$ https://a-nas.ru/sasha2$1 [R=302,L]
RewriteRule ^(sasha2(/[a-z0-9-]+)*)$ https://a-nas.ru/$1/ [R=301,L]
```

На новом хостинге они нужны, только если адреса без косой черты на конце не открываются или сайт доступен по http.

### 6. После переезда

- **Переадресация со старого адреса.** Чтобы не потерять позиции в поиске, со старых адресов `a-nas.ru/sasha2/…` нужно поставить постоянную переадресацию (301) на новые.
- **Поисковики.** Подтвердить сайт в Яндекс Вебмастере и Google Search Console, отправить карту сайта `sitemap.xml`. Коды подтверждения вписываются в `VERIFY` в начале `ishodniki/_src/sasha2/build.js`, номер счётчика Яндекс Метрики — в `METRIKA`. После правки сайт нужно собрать заново.
- **Почта формы.** Письма уходят с адреса `no-reply@<ваш домен>`. Чтобы они не попадали в спам, для домена нужна запись SPF, разрешающая отправку с сервера хостинга (настраивается в панели хостинга или у регистратора домена).

## Как вести сайт дальше

Все правки делаются в исходниках, затем сайт собирается заново командой из раздела 2 и загружается на хостинг.

| Что поменять | Где |
|---|---|
| Телефон, почту, Telegram | `CONTACTS` в начале `ishodniki/_src/sasha2/build.js` |
| Тексты об эксперте, цифры, компетенции, кейсы, карьеру, короткие описания услуг | блок `CONTENT` в `ishodniki/_src/sasha/index.html` |
| Подробные тексты услуг | `SERVICE_PAGES` в `ishodniki/_src/sasha/build.js` |
| Добавить статью в блог | новый файл в `ishodniki/_src/sasha/blog/`, правила в `ishodniki/_src/sasha/README.md` |
| Оформление | `ishodniki/_src/sasha2/site.css` |
| Фото эксперта, значки, картинку для соцсетей | `ishodniki/_src/sasha2/static/` |
| Баннер первого экрана и фон тёмных полос | `ishodniki/_src/sasha2/g/` |

Картинка новой статьи: положите в `ishodniki/a-nas.ru/sasha/img/blog/` четыре файла `<адрес-статьи>-1200.webp`, `-720.webp`, `-440.webp` и `-1200.jpg` (ширина в точках, пропорции 16:9). Если их нет, сайт возьмёт картинку по ссылке из шапки статьи через сторонний сервис сжатия.

Подробности устройства: `ishodniki/_src/sasha2/README.md`.

## Чего в архиве нет

- **Исходников игры «Нейрогонка»** (проект Blender и код, около 100 МБ). В архиве лежит готовая сборка игры, она работает без них. Исходники нужны, только чтобы менять саму игру; они хранятся в репозитории GitHub `robot-sites/sites`, папка `_src/sasha/neurogame-src/`.
- **Автоматики GitHub.** На `a-nas.ru` сайт пересобирался сам при появлении новой статьи (файл `ishodniki/.github/workflows/sasha2.yml` приложен для справки). На новом хостинге сборку нужно запускать вручную или настроить свою.
- **Обращений из формы**, накопленных на старом сервере (`_data/obrascheniya.csv`): они остаются на сервере `a-nas.ru`.

## Что сайт берёт со стороны

- 3D-кабинет и игра загружают шрифты с Google Fonts. Остальные страницы используют шрифты из папки сайта.
- Кнопка Telegram открывает чат по номеру телефона. Она работает, если в настройках Telegram у владельца номера разрешён поиск по номеру.

## Известные недоделки

- Доставка писем из формы не проверена реальным письмом.
- Нет страницы политики обработки персональных данных; под формой стоит короткая строка о согласии.
- Тексты услуг не выверены самим экспертом.
